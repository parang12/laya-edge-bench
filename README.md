## 프로젝트 소개

IoT 게이트웨이에서 센서 메시지와 수신 기록을 바탕으로 **현재 상태**와 **필요한 대응**을 판단합니다. 기준 모델과 경량화한 모델이 같은 환경에서 실행되는지 확인하고, 판단 성능과 자원 사용량을 비교합니다.

같은 기준 모델에서 출발한 **파인튜닝 FP32**, **INT8 양자화**, **소형 학생 FP32**에 동일한 시험 기록을 재생합니다. 전체 점수와 함께 센서 이상이나 수신 중단을 놓치거나, 경고가 필요한 상황에서 관측을 계속하기로 판단한 경우도 확인합니다.

## 시스템 구성

~~~mermaid
flowchart LR
    S["가상 IoT 센서 노드"] -->|"센서 메시지 발행"| B["MQTT 브로커"]
    B -->|"센서 메시지 전달"| G
    subgraph EDGE["IoT 게이트웨이"]
        G["게이트웨이 처리부"] -->|"최근 관측 요약"| M["Laya 경량화 모델"]
        M -->|"상태 판단 · 대응 판단"| G
    end
    G --> R["판단 로그 · 경고 · 결과표"]
~~~

가상 센서 노드는 정상 범위의 값, 범위를 벗어난 값, 메시지 끊김과 복구를 재현합니다. 첫 구현에서는 온도 센서를 예시로 사용합니다. 게이트웨이는 최근 센서값, 변화량, 마지막 메시지 이후 경과 시간을 정리해 Laya를 로컬에서 실행합니다. 메시지가 없는 동안에도 수신 상태를 확인하고 모델의 상태 판단과 대응을 로그에 남깁니다.

| 판단 작업 | 모델에 묻는 질문 | 선택지 |
|---|---|---|
| **상태 판단** | 최근 센서값과 수신 기록에서 어떤 상태가 관측되는가? | 정상 · 센서값 이상 · 데이터 수신 중단 |
| **대응 판단** | 관측된 상태에서 게이트웨이가 어떤 대응을 해야 하는가? | 계속 관측 · 경고 발생 · 연결 점검 요청 |

센서 종류와 단위, 관측 구간, 정상 범위와 수신 중단 기준은 팀에서 합의합니다. 시나리오별로 기대 상태와 기대 대응을 미리 기록합니다. 수신 중단은 게이트웨이가 관측한 상태로 채점하며, 원인을 구분하는 실험에는 추가 신호를 사용합니다.

구조도의 **Laya 경량화 모델** 자리에 기준 FP32, INT8, 소형 학생 FP32를 각각 연결해 비교합니다.

## 비교 실험

| 모델 | 준비 방법 |
|---|---|
| **기준 FP32** | 원본 Laya multilingual을 두 판단 작업에 맞춰 파인튜닝하고 검증셋에서 고른 체크포인트를 저장합니다. |
| **INT8 양자화** | 같은 기준 FP32 체크포인트를 양자화합니다. |
| **소형 학생 FP32** | 기준 FP32를 교사로 사용해 더 작은 학생 모델에 판단을 증류합니다. |

**평가 방법.** 학습·검증·시험 시나리오를 실행 단위로 나누고, 같은 기록에서 만든 변형은 같은 분할에 둡니다. 기준 모델과 설정을 고정한 뒤 세 모델을 같은 기기에서 실행합니다. 동일한 시험 입력과 정답표를 사용하고, 모델별 실행 환경과 측정 조건을 기록합니다.

| 측정 항목 | 비교 내용 |
|---|---|
| **판단 성능** | 상태·대응별 정확도, Macro-F1, 출력 적합률, 유형별 오판 |
| **자원 사용량** | 모델 파일 용량, 실행 중 최대 메모리, 모델 호출 지연 |
| **시나리오 기록** | 기대 상태·대응, 실제 상태·대응, 정오 및 출력 오류 |

출력 적합률은 모델이 정해진 선택지로 답한 비율입니다. 모델 호출 지연과 MQTT 전달을 포함한 전체 응답 시간은 구분해 기록합니다.

**평가 데이터.** AI4I와 CONTEXT는 산업 설비 상태를 살펴본 예비 실험입니다. AI4I의 splits.csv는 그 실험의 분할 기록으로 보관합니다. 최종 비교용 데이터는 MQTT 관측 기록과 시나리오별 상태·대응 정답표로 별도 구성합니다. 세 모델이 같은 기록을 받도록 시나리오와 분할을 실행 단위로 고정합니다.

## 진행 계획

| 단계 | 작업 | 완료 기준 |
|---|---|---|
| **1주차 · 기준 모델과 시뮬레이터** | 1명은 MQTT와 IoT 시스템을 구현하고, 2명은 상태·대응 사례를 준비해 FP32 모델을 파인튜닝합니다. | 정상·센서값 이상·수신 중단을 재생하고, 모델의 두 답이 결과표에 남습니다. |
| **2주차 · 경량화와 측정** | 기준 체크포인트와 공통 시험셋을 고정하고, INT8과 소형 학생 모델을 준비합니다. | 세 모델의 판단 성능과 자원 사용량을 같은 조건에서 측정합니다. |
| **3주차 · 결과 분석과 시연** | 주요 실험을 재실행하고 오판을 분석한 뒤 보고서와 발표 자료를 작성합니다. | 비교표·그래프, 논문 초안, 발표 자료, 시연 영상을 준비합니다. |

**현재 상태 · 설계 및 예비 실험 단계.** 세 모델의 비교 점수와 실행 안내는 시뮬레이터와 평가 흐름이 연결된 뒤 추가합니다.
